# SALORIS

**Human Resilience Beyond the Horizon.**

SALORIS is an astronaut health-monitoring and decision-support platform designed to support crew health assessment during space missions.

## Project Structure

- `frontend/` – React and TypeScript application.
- `backend/` – Java Spring Boot application.
- `docs/` – Architecture, API and technical documentation.
- `research/` – NASA and CSA scientific references and research.

## Technology Stack

- Frontend: React, TypeScript, Vite
- Backend: Java, Spring Boot
- Database: PostgreSQL

## Development

The frontend and backend are maintained separately and integrated through REST APIs.

## Research

Scientific information and external resources will be documented in the `research/` directory.
